# Releasing Everything Next

GitHub Releases are also the update feed used by installed release builds.

## One-time updater signing setup

Generate a Tauri updater signing key pair on a trusted machine:

```powershell
cargo tauri signer generate -w "$HOME\.tauri\everything-next.key"
```

Keep the private key out of the repository.

Configure the repository with:

- Actions secret `TAURI_SIGNING_PRIVATE_KEY`: the private key contents (or a value accepted by the Tauri CLI).
- Actions secret `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: the key password, if one was configured.
- Actions variable `TAURI_UPDATER_PUBLIC_KEY`: the complete public key printed/generated by the signer command.

The public key is compiled into release builds through `TAURI_UPDATER_PUBLIC_KEY`. Local builds that do not define it simply skip update checks.

## Publishing

1. Update the application version in both `Cargo.toml` workspace metadata and `src-tauri/tauri.conf.json`.
2. Run `./scripts/check.ps1`.
3. Run the **Release** GitHub Actions workflow, or push a `v<version>` tag.

The workflow builds the Windows NSIS installer, signs the updater artifact with the Tauri private key, creates the GitHub Release, uploads the `.sig` file, and generates `latest.json` for the updater endpoint.

Installed release builds query:

`https://github.com/StephanOrgiazzi/EverythingNext/releases/latest/download/latest.json`

When a newer version is available, Everything Next offers **Install** or **Later**. The updater uses the NSIS installer; on Windows the app exits before installation, and the existing installer hooks stop/recreate the private Everything service during the upgrade.

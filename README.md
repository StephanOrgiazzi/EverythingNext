# Everything Next

Client Windows pour **Everything 1.5**, construit en Rust avec **Tauri 2 + Leptos**. L’installateur embarque Everything **1.5.0.1418b x64** et **Everything SDK3 3.0.0.9** : aucune installation préalable d’Everything n’est nécessaire.

Le renommage complet depuis Everything Modern est appliqué dans cette branche, y compris aux identifiants techniques, aux données locales, aux services, aux packages et aux artefacts.
